# 长三角特价航班速查

长三角四机场（常州奔牛CZX / 无锡硕放WUX / 上海虹桥SHA / 上海浦东PVG）出发特价航班速查单页应用。

## 功能特性

- 🌏 **四机场覆盖**：常州/无锡/上海虹桥/上海浦东出发航线
- 💰 **实时价格**：集成TripNow API，每日自动刷新
- 🪃 **回旋镖航线**：两程/三程回旋组合，智能计算最优价
- ⭐ **收藏功能**：本地收藏关注航线
- 📈 **价格走势**：历史价格对比，标注涨跌
- 🌙 **深色模式**：支持明暗主题切换
- 📱 **响应式设计**：适配桌面和移动端

## 文件说明

| 文件 | 说明 |
|------|------|
| `全球特价航班速查_2026年9月.html` | 主页面，单文件HTML，直接浏览器打开即可 |
| `flight_daily_refresh.py` | 每日价格自动刷新脚本（Python） |
| `tripnow_prices_v3.json` | 价格缓存数据 |
| `flight_verification_report.md` | 12条回旋镖航线深度核查报告 |

## 价格门槛

- 国内直飞：≤ ¥600
- 国际/港澳台直飞：≤ ¥1000
- 两程回旋镖：≤ ¥1000
- 三程回旋镖：≤ ¥1500

## 数据源

- 航班号/时刻：飞常准
- 票价：TripNow 实时查询
- 机场交通：高德地图

> ⚠️ 票价为实时参考价，可能随舱位余量波动，实际价格以航空公司/OTA购票页面为准
